# AI Studio 2.6 — 源码公开版（非商用）

AI Studio 2.6 以多流水线列表组织多个任务，每条流水线可配置独立团队与预算，固定角色内可安排多位 AI 成员。此源码基于标识为 2.6 的商业候选客户端整理；真实购买及跨设备授权并未接通。

本仓库公开可供学习和非商业分发的项目自有源码。除用户作品例外外，不得商用或出售软件及其代码，也不得将其作为收费产品、软件服务的一部分；允许用户使用软件制作并出售自己依法享有权利的作品。第三方依赖另遵守其各自许可。详细授权以发布时的 LICENSE 为准。

与 1.0 相比，2.6 增加多流水线列表，以及每条流水线独立的团队与预算。本候选客户端的本机并发限制与能够保存多少条配置不是同一概念。

与 4.0 相比，4.0 增加自由工位图、每位 AI 的 MCP 插件设置、兼容通用 API 的制作工位、媒体上传与权限分配，以及主 AI 辅助规划。实际能力依模型、工具与配置而定。

AI Studio 4.0 本地完整版（Windows）已正式上架，一次性售价 25 美元。 [购买 AI Studio 4.0](https://download.tsstudiohub.com/)

## 运行与配置

在 Windows 安装 Python 3.12 或兼容版本，在仓库根目录运行 `python client/store_bootstrap.py`。软件会初始化独立本地数据目录；初次使用需在界面配置所需助手、模型和工具。先保存配置，确认预算后再执行任务；第三方助手及 API 按其服务商要求安装、登录和计费。
