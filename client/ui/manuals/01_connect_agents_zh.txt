如何接入智能体
本源码仅限非商业使用；源自历史商业候选版本，本机控制器仍有运行数量限制，该限制不代表商业授权。购买、支付及跨设备授权服务尚未接通。4.0 完整程序的购买渠道和价格待正式公布。用户可以依法商业使用或销售自己创作的作品，作品权利不因使用本软件而转移；使用仍须符合第三方权利及服务条款。
1. 接入前先准备什么
建议先确认一位可工作的编程助手，再增加研究、动画等成员。不要为了“看起来连上了”同时重装所有软件。
在本机准备助手和自己的账户。自动执行需要对应 CLI 或支持交接协议的程序；只有桌面聊天窗口的助手先按人工交接配置。官方登录、2FA、授权弹窗由你本人处理。
准备当前任务需要的工具。Godot 项目需要 Godot；Blender 动画需要 Blender 和相应 MCP。纯软件任务不必为此安装 Blender。
打开软件的接入页面。入口为“角色与接入”；发布候选的“首次使用准备 / 设置本机软件与模型”可填写已安装 exe 路径。桌面自用版使用自己的现有本机配置，不从商业候选复制私密配置。
会员额度不计入预算
页面中的 USD 只用于纳入本地账本的 API 费用。会员成员显示“工位预算不可用，以你的会员额度作为标准”时，表示不设置美元限额；不是会员用量为 0，也不是无限使用。会员剩余 Token、速率或时段额度没有提供时，应到自己的服务商账户查看。
本软件接入已有 AI 编程助手，让它使用自己的工具和账户；不是出售模型/API 额度。Claude Code 经你已有 API/网关运行仍可能产生 API 费用。人工桌面交接、外部程序及其费用需要独立核对，不应冒充会员额度。
操作流程示意，不是软件截图。每一步的状态都以当前软件返回的真实结果为准。

“已登记”“本地可用”“协议通过”“模型实际连通”是不同层级。助手尚未出现在本版可用执行方式中时，不要随意借另一个适配器名称冒充它。
3. 在“角色与接入”登记助手
点击“＋ 添加智能体”。若当前窗口提供助手预置模板，先选择与你实际安装方式匹配的原生CLI或桌面人工模板；不要把桌面模板误选成CLI。预置只填配置，不安装、不登录、不发模型请求。
填写一个稳定、唯一的智能体标识，例如 my-codex 或 my-claude-art；名字不能代替账号验证。按真实运行程序核对执行方式：原生自动CLI、桌面人工交接、研究API、外部协议程序应分别选择。
填写模型。可留空继承当前登记的默认值；填写时使用你账户实际可用的名称，不把不存在的模型名当作已订阅。
选择可用工具类型：玩法 / 代码、动画 / 资源、整合 / 检查、资料研究。选择表示准备把任务交给它，并不自动安装工具或证明权限。
只有已有非敏感配置标识时才填设置引用。有需要时填写兼容服务地址；地址栏不是密钥栏。
点击“保存智能体”。保存登记不会发模型请求。再为新流水线或具体成员选择这位助手。
修改默认接入只影响后续配置。已经开始的流水线使用自己的冻结快照，不能通过改全局默认偷偷更换正在执行的成员账号或模型。
4. 登录、密钥与本地隐私
Codex 订阅接入应由本人完成 ChatGPT / Codex 登录。本软件的订阅路径不要求你改成 OpenAI API Key，也不会替你处理密码或 2FA。
Kimi 原生接入目前只支持已明确的 managed OAuth 会员配置。先在 Kimi 官方程序完成自己的会员登录，再选择已配置模型；API Key、自定义网关或混合 API 配置不会静默当作会员继续。所选会员凭据只复制到当前私有工位配置，不把原账户秘密写入任务包。
需要密钥的接入在助手卡片点击“设置凭据”，通过独立的密码输入框填写。如果勾选本机记住，Windows 版本使用私有凭据区加密保存。不同提供方应使用各自匹配的凭据；不要把默认网关密钥当成所有服务都能用。
不要把密码、Token 或 API Key 写进项目目标、成员分工、普通 JSON 配置、交接文件或截图。
账号、订阅、模型可用性与第三方收费由各服务商决定；本软件保存一份设置不会开通账户。
外部桌面助手是否服从工程权限或保留聊天数据，由其自身产品与账户控制，本软件没有绝对防绕过或防破解保证。
5. 配置工具与检查连接
在“MCP 插件”添加或导入受信任的 MCP 服务配置，选择归属工具类型，按需要启用。软件会为当前成员筛选工具，不应让纯研究成员得到所有工程写入权限。
如配置需要敏感环境值，使用 ${ENV_VAR} 引用，并通过插件的私有变量入口设置实际值。不要把明文密钥写入公开配置。
先点击助手卡片的检查连接。本地检查只核 CLI、登录记录、设置或配置状态；“本地可用 / 已配置”并不等于已经成功调用模型。
如界面提供模型实测确认，先核对指定助手、模型和测试额度。逐量 API 实测会产生请求，需单独明确批准；不要为准备工作反复做收费测试。
Blender 安全模式保持开启。
本轮修复验证基线为 Blender 5.2.2：使用兼容的原生场景 / 渲染 API，先核对当前隔离文件和工位身份。保存后重载源文件核验持久化；不能只凭“保存成功”或内存中的图像数量认定完成。
遇到安全层拒绝，应让助手修正兼容脚本；不要关闭安全模式。清单、哈希采用记录和普通文件说明由助手的正常文件工具处理，不要逼 Blender 脚本导入被禁模块或执行文本数据块。
6. 桌面人工交接与接入失败
桌面人工交接会保存当前任务包，然后进入“等待桌面交接”。你在原助手窗口完成任务，再按该任务包提供的 completion 模板和文件位置回传真实文件与结果；等待期间不持续调用模型。
任务、工位、成员、提供方、exchange 和计划身份必须匹配当前包。不要拿另一条流水线的旧结果、旧 revision 或只贴一句“完成了”替代回传。任务修改后旧包可能失效，必须使用当前包。没有理解回传协议时，先使用已经支持的原生自动接入。
一个助手离线不会让独立工位的已有成果丢失；可以继续不依赖它的分支。依赖它的工位仍需等待，不能提前说整合完成。收费调用已经发出却没有明确费用时，该流水线会保持停止，先核对真实费用再决定恢复；其他流水线有独立账本。
依据实际工作源与验证记录整理；界面入口以当前版本显示为准。已配置 / 免费协议通过不能替代模型任务实测。发布者展示名 AI Studio contributors；客服：Project issue tracker。展示名不是已核验公司法律名称。此HTML离线自包含，不用外网字体、追踪、脚本或远程图片；图为示意。


只关闭界面，后台继续运行；退出后台默认请求暂停并保存，重开后不会自动恢复。取消只针对本次任务：已生成内容不可恢复，流水线、工位、连线及预算配置保留；先编辑并保存新任务，再明确开始。历史费用、用量和尝试不会退款或清零。


助手兼容更新：条件与处理方式
当已登记助手的执行接口保持兼容时，助手的常规更新不要求同步更新AI Studio；无需仅因工具换了版本目录就重复安装本软件。这不保证任何新版本或任意助手都能自动适配。

仅当前Windows用户的官方Codex受管绝对程序路径已失效且布局符合规则时，才检查同一受管目录中的真实可执行文件及有效OpenAI签名。只有唯一有效候选才自动定位；仍存在的程序、自定义路径、相对命令或其他用户目录不自动替换。候选不唯一、签名不符或越出受管范围时，停止该接入并提示核对，不替换为任意PATH中的程序。原命令尾部参数与账号、模型、计费和MCP配置保持原样；路径恢复不会代替登录、会员额度或收费批准。

Claude Code、Kimi和外部程序仍须逐一核对实际接口、模型配置、权限及工具/MCP兼容性。帮助或版本命令正常，不等于模型与MCP端到端验证通过。若第三方改变接口或输出协议，可能需要相应适配修订；桌面人工交接仍按真实任务包回传，不冒充自动执行。

连接失效时，依赖该接入的任务保留已落盘内容并等待处理；符合依赖的独立工位可继续，仍受本机资源、助手额度和费用核清状态约束。恢复连接后核对状态并按界面明确恢复，费用批准与累计账本不会因路径更新而重置。

外部协议程序登记时应使用本机真实可执行文件的绝对路径，不使用相对命令或.cmd、.bat、.ps1脚本启动器；尾部参数按原配置保留。预检复用实际执行的命令校验，配置通过仍不证明第三方助手模型、权限或回传协议已经端到端成功。
