工位使用说明
本源码仅限非商业使用；源自历史商业候选版本，本机控制器仍有运行数量限制，该限制不代表商业授权。购买、支付及跨设备授权服务尚未接通。4.0 完整程序的购买渠道和价格待正式公布。用户可以依法商业使用或销售自己创作的作品，作品权利不因使用本软件而转移；使用仍须符合第三方权利及服务条款。
1. 哪一版可以自由编辑工位
1.0：固定玩法、资源、整合和研究分工，按已有逻辑角色选择接入。2.6：固定逻辑角色，可组成多成员团队并设置分层预算。3.0：自由添加任意名称的工位，可重复使用同一种工具类型，配置多成员及多对多连线。本说明的自由图操作适用于 3.0。
“工具类型”用于能力和 MCP 接入，不限定你给工位取什么名字。比如“世界设定组”和“对白组”可以都是玩法 / 代码类型；“武器波纹”和“界面特效”都可以是动画 / 资源类型。
自由工位示意。资料组沿原调用线回传，不需要再画一条反向成果线。
2. 添加、改名、删除与暂停编辑
在“新建 / 编辑”中打开自由工位图。输入“新工位名称”，选择“工具类型”，点击“＋ 添加工位”；也可以使用“插入推荐示例”。
点击节点，在右侧属性中填写工位名称、本工位任务、执行时机和成员。拖动节点标题只改变布局。
选择“主动制作”：满足必需交接依赖后执行；选择“按需调用”：只有收到实际 call 请求才执行。未收到请求的按需节点休眠，不需要为了完成度强行调用。
点击“移除工位”或成员的“移除成员”进行删除，再保存配置。旧身份、历史产物与费用仍用于审计，不能靠删除成员清零花费。
已开始的流水线先暂停并收尾，再编辑。
点击“暂停并保存”，等到实际状态为已暂停、后台工位退出后，再编辑任务、增删工位、连线或预算。已开始成员的账号、模型和身份保持；若要不同助手，用新成员身份或克隆为新流水线。
改名和拖动位置不会重新制作已完成产物。修改目标、工位任务、分工、交接要求或文件范围，可能使相关工位、调用者、下游和 QA 需要重新执行；旧费用、尝试和候选不会清零。只调预算不会重做所有 DONE 工位。
3. 一个工位如何配置多个 AI 成员
选中工位，点击“＋ 添加AI成员”。为每位成员选择真实可用的执行提供方，填写明确分工与成果。
第一成员是正式汇总负责人。其他成员先在自己的独立候选目录工作。负责人会实际读取可用贡献，合并资源、说明冲突，再形成正式成果。
“必需成员”决定依赖要求。可选成员失败不会自动抹掉其他人的进度，但不能将失败结果写成已完成；第一汇总负责人即使被设置为可选，也仍要完成正式汇总才能发布该工位成果。
多人不是几位 AI 同时改同一个文件夹。独立候选、真实文件交接、显式冲突与汇总是必要步骤；多人汇总可能新增真实调用，要给负责人留额度。
示例：武器动画工位
第1成员：完成正式动画源文件、合并可用助手建议、给出真实帧清单。
第2成员：检查相机、透明边缘和构图，提交可检查的候选与修改说明。
第3成员：检查交接合同，不伪造“已经看过”或“已下载”的素材。
4. 自由连线：成果交接与按需调用
可以从输出点拖到接收节点的输入点，或依次点击输出点和输入点；也可用下方“表单连线”选择来源、接收工位和连接方式。点击已有线即可修改合同。
| 连接方式 | 方向与触发 | 如何判断完成
| 成果交接 · 蓝色实线 | 来源制作完成后，把实际文件包传给接收方；每根线有自己的要求、文件过滤和必需标记。 | 必需输入未就绪时接收方等待。一个来源可传给多个接收方，每个消费者得到独立输入包。
| 按需调用 · 紫色虚线 | 方向是调用者 → 被调用工位。调用者遇到具体资料或资源问题后才触发，结果沿原线自动回传。 | 不需要画返程线；同一工位可以服务不同调用者，各调用有独立身份、目录和账本记录。
必需成果交接关系不能形成依赖环，保存时会拒绝。按需调用可以在图上画环，但当前实际调用链遇到反锁会停止，并受有限深度、次数和预算约束。可选输入缺失应记录问题，不能虚构文件替代。
5. 每根连线填写什么要求和文件
填写“这根连线的交接要求”，说明要做什么、交什么、接收方怎样检查。不要只写“给下一个 AI”。
交接要求示例：
交付18张256×256 RGBA透明帧、30fps、manifest和可编辑Blender源文件。
接收方按manifest顺序整合；攻击伤害与冷却仍由玩法代码管理。
说明真实采用的建议、检查结果和缺失项；不要把失败或未核实素材说成通过。
“交接文件过滤 · 每行一个相对glob”针对来源工位的实际输出目录。例如动画输出位于 art/ 下时，可以填写：
art/frames/*.png
art/manifest.json
art/source.blend
art/HANDOFF.md
普通代码输出通常在 game/ 下，相应使用 game/** 或更窄范围。留空使用后端的实际交接范围。不能填写绝对磁盘路径、../、私密配置或别的流水线目录。要求是按每根线独立保存的；同一来源给不同接收方可使用不同范围。
主机按真实文件生成清单和哈希。助手可记录输入清单中声明的哈希与采用建议，但不能谎称自己重新计算过哈希、下载过素材、看过视频或取得使用授权。
6. 总预算、工位共享预算和成员预算
会员额度不计入预算
页面中的 USD 只用于纳入本地账本的 API 费用。会员成员显示“工位预算不可用，以你的会员额度作为标准”时，表示不设置美元限额；不是会员用量为 0，也不是无限使用。会员剩余 Token、速率或时段额度没有提供时，应到自己的服务商账户查看。
本软件接入已有 AI 编程助手，让它使用自己的工具和账户；不是出售模型/API 额度。Claude Code 经你已有 API/网关运行仍可能产生 API 费用。人工桌面交接、外部程序及其费用需要独立核对，不应冒充会员额度。
| 层级 | 含义 | 注意
| 流水线总 API 预算 | 本条所有逐量 API 工位共用的累计上限。 | 两条流水线账本独立，不互相挪余额；失败调用同样计入。
| API 工位团队共享上限 | 同工位所有收费成员共同使用。 | 各成员不是各自再获得整份工位预算；汇总和返修也计入本工位。
| AI 成员累计上限 | 该成员在这条流水线的 API 调用累计上限。 | 成员限额不能高于工位团队限额，工位限额不能高于流水线总限额。
| 会员 / 人工外部 | 会员用量由服务商决定；人工与外部费用另核。 | 不设置会员美元预算；不可把逐量 API 改个标签冒充会员来绕过账本。
建议总预算覆盖实际计划的 API 工位预算，并给汇总、返修预留余量。各工位上限之和并不自动增加总额；总预算仍是共享天花板。软件显示的预留是执行中的会计占用，不是已到账的充值。
确实因美元额度不足停下时，可生成预算申请。用户批准增加工位 / 成员限额后不会自动收费，仍需明确恢复。只提高流水线总额，可能仍被成员或工位上限挡住；软件会重新检查并保留累计花费。
连接失败、次数上限、会员额度耗尽、未知费用不是美元增额申请。费用未知必须先核对真实记录；不能填写猜测的 0 美元来继续。
7. 谁负责交付，什么时候才算 DONE
“游戏 / 软件验收交付工位”可以选择图中的实际节点。它要交可运行项目，接受真实导入、启动和功能检查，并打包。未选择交付工位时可以归档实际图产物，但不能说游戏或软件功能 QA 已通过。
选中的交付节点可以使用已正式完成的 base 或实际 call 运行结果，身份与 revision 必须匹配当前交付。该终端通过不等于其他主动工位已经完成；全线 DONE 还要求主动工位及实际已创建的运行 / 调用满足完成条件。未调用的休眠按需节点不必执行。
独立分支失败时，已经完成的终端产物、原费用和 QA 可以保存，后续恢复只继续未完成工作。只有符合明确可选排除策略的非交付分支，才可带真实警告结束；失败工位本身仍显示失败，不会伪改为 DONE。
依据实际工作源与验证记录整理；界面入口以当前版本显示为准。已配置 / 免费协议通过不能替代模型任务实测。发布者展示名 AI Studio contributors；客服：Project issue tracker。展示名不是已核验公司法律名称。此HTML离线自包含，不用外网字体、追踪、脚本或远程图片；图为示意。


只关闭界面，后台继续运行；退出后台默认请求暂停并保存，重开后不会自动恢复。取消只针对本次任务：已生成内容不可恢复，流水线、工位、连线及预算配置保留；先编辑并保存新任务，再明确开始。历史费用、用量和尝试不会退款或清零。
