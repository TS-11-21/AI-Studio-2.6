如何创建流水线
本源码仅限非商业使用；源自历史商业候选版本，本机控制器仍有运行数量限制，该限制不代表商业授权。购买、支付及跨设备授权服务尚未接通。4.0 完整程序的购买渠道和价格待正式公布。用户可以依法商业使用或销售自己创作的作品，作品权利不因使用本软件而转移；使用仍须符合第三方权利及服务条款。
1. 先准备一条小而可验收的任务
首次建议使用“扇气 Demo · 验证模板”，先验证接入、真实资源、交接与验收，再投入原项目。新流水线创建在独立目录，不覆盖原游戏工程。
先完成智能体接入说明的登记与本地检查；自由图设计可参考工位使用说明。创建、保存、刷新面板不会调用模型。
生命周期示意。等待资料或交接时结束模型调用，依赖就绪和批准后才继续。
2. 按界面创建并保存
在“流水线”点击“＋ 新建流水线”，进入“新建 / 编辑”。
填写流水线编号：以字母或数字开头，后续使用字母、数字、下划线、短横线，最多64个字符，例如 my-fan-001。已有目录不会覆盖；已取消本次任务的流水线保留，保存新任务后可再次使用。
选择任务类型：扇气验证模板、自定义 Godot 游戏，或软件（Python / HTML / Node）。填写项目目标与验收条件。
填写本条流水线总 API 预算。界面默认数值仅是预填，不是软件替你充值或批准费用；会员额度另算。
3.0 添加工位与成员、建立交接 / call 线、填写连线要求和文件过滤，并选择真实验收交付工位。1.0 / 2.6 按已有逻辑角色和团队表填写。
核对各成员提供方、模型、分工、必需标记和三层预算，点击“创建流水线”或“保存流水线配置”。此时仍没有模型调用。
目标示例：
在独立Godot工程制作可左右移动、攻击木桩的2D扇气演示。
伤害每次10点，冷却0.6秒，拒绝冷却内重复伤害。
整合18张256×256透明RGBA帧，30fps，保留真实Blender源文件和manifest。
必须实际运行玩法/帧数量/透明素材测试，交付可打开源码与机器日志。
不要改原工程，不要求完整人物后空翻，不发布到网络。
开始后的流水线使用保存的提供方、MCP、策略和任务快照。改全局默认不会悄悄替换这条已执行流水线；新助手要通过暂停后的显式编辑加入。
3. 开始之前确认什么
会员额度不计入预算
页面中的 USD 只用于纳入本地账本的 API 费用。会员成员显示“工位预算不可用，以你的会员额度作为标准”时，表示不设置美元限额；不是会员用量为 0，也不是无限使用。会员剩余 Token、速率或时段额度没有提供时，应到自己的服务商账户查看。
本软件接入已有 AI 编程助手，让它使用自己的工具和账户；不是出售模型/API 额度。Claude Code 经你已有 API/网关运行仍可能产生 API 费用。人工桌面交接、外部程序及其费用需要独立核对，不应冒充会员额度。
选中刚创建的流水线，点击“开始流水线”。
在“确认开始此流水线”中核对本条编号、各活跃成员的提供方、模型、累计限额，确认不是旧任务。
对逐量 API 成员逐一勾选本次允许执行者，并勾选“我批准所选 API 工位在以上预算与已有调用次数限制内执行”。不勾选时只允许订阅工位继续，收费成员等待批准。
点击“确认并开始”，然后看实际状态与日志。某助手失败并不取消其他可独立执行的分支，但依赖输入未完成时下游仍等待。
会员 Token、速率或使用上限仍由你的账号决定。API 单次停止阈值、预留额和 CLI 报告费用不保证服务商最终硬账单上限；模型停止后的真实报告费用可能高于预留，仍必须计入累计账本，不能清成 0。
4. 看状态，不用让模型持续报进度
| 状态 / 现象 | 意味着什么 | 你要怎么做
| 待执行 / 执行中 / 汇总 | 工位已就绪或有受控调用正在执行。 | 看当前成员、真实动作和日志；不要按“开始”制造重复调用。
| 等待依赖 / 等待资料 | 尚缺交接包或具体研究请求。 | 独立分支可继续；等真实输入就绪，不靠持续问模型“好了吗”。
| 等待桌面交接 | 当前任务包已经保存，等人工助手按协议回传。 | 使用当前包的 completion 模板和身份；关闭旧任务包，别混用旧 revision。
| 等待接入 / 等待费用批准 | 本地程序、登录或本次 API 批准未就绪。 | 修对应接入或明确批准；恢复不会替你登录、开会员或自动填密钥。
| 等待预算批准 | 真实美元余额不足，已提出当前申请。 | 可拒绝或批准；增额不自动开始，之后明确恢复。会员额度不足不是这种申请。
| 预算 / 次数停止、未知费用 | 有限次数或费用安全门禁被触发。 | 先读真实原因和账单，不一键扩大次数；未知费用须据服务商用量记录核对。
| 失败 / 已中断 | 有真实错误或自有后台停止，进度与费用保留。 | 连接修复后重试相应失败项，或恢复原任务；DONE 成员不会因此全部重做。
| 已完成 | 真实产物、当前交付身份和要求的机器验收均满足。 | 打开交付和当前 QA 记录，仍区分有限功能测试与完整产品质量。
自动返修需在“运行策略”启用，最高两次，并受已批准预算与原提供方限制；不会自动充值、无限重试或换收费供应商。已经发生但没有明确费用的调用会阻止该流水线继续收费，独立流水线不会共用它的费用记录。
5. 暂停、编辑、恢复与重启
点击暂停并保存。先进入 PAUSING，停止派发新工作；当前受控调用按宽限收尾，必要时只停止本流水线拥有的 CLI。
等真实状态为 PAUSED、后台工位退出，并查看保存记录。Blender 保存只在文件路径、隔离标记和工位身份均确认时执行；显示未验证或未保存时，不能称内存场景已保存。
再编辑目标、工位任务、成员分工、连线或额度；旧产物、尝试和费用保留。改任务与合同会使相关工位和下游重新制作 / QA，改名和布局不会。
点击恢复，再次核对 API 成员审批。原 DONE 结果按适用 revision 复用，继续未完成工位；只改预算不会重做所有完成项。
开启自动保存时，3.0 当前运行器约每15秒保存状态记录；这是记录与磁盘文件哈希检查，不是每15秒无条件写 Blender 场景。暂停 / 收尾会生成检查点版本，当前保留最近5份；修订历史与费用另行保留。
只关闭界面，后台继续运行；退出后台默认请求暂停并保存，重开后不会自动恢复。取消只针对本次任务：已生成内容不可恢复，流水线、工位、连线及预算配置保留；先编辑并保存新任务，再明确开始。历史费用、用量和尝试不会退款或清零。 使用“退出后台并暂停任务”时等待保存和进程收尾；强制结束所有进程、断电等仍可能导致中断。尚未写盘的内存不能保证找回；被中断收费调用费用未知时先核对账单。
6. 取消本次任务：保留流水线配置
需要以后继续，选“暂停并保存”。
选中具体流水线后，点击“取消本次任务”，弹出默认“否”的确认：“取消本次任务，已生成内容不可恢复；保留流水线及工位/连线/预算配置；可以先暂停修改；是否确定取消？”选择否或关闭弹窗不会删除内容。
取消只能在本次任务已停止、暂停收尾完成后执行。确认后清理本次任务已生成内容，保留同编号流水线及工位、连线、预算配置；取消状态下不能直接开始或恢复。先编辑并保存新任务，使状态回到待执行，再明确开始并核对费用审批。已经导出的工程副本和外部服务记录不自动擦除。
必要取消 / 费用审计、已使用额度或试用计数不会借取消清零；已经产生的会员用量和服务商费用不会自动退款。未显示这个入口的桌面版本不要用手动删目录冒充软件取消流程。
删除整条流水线
删除流水线与取消本次任务不同。在主页选中流水线后点击“删除流水线”，确认默认“否”。删除会移除整条流水线配置及保存内容，无法恢复；已删除编号不能再次使用，请为新流水线使用新编号。先暂停并等待所有任务进程退出；费用未知时需先核对。已经产生的费用、用量、累计尝试及必要审计记录不会退款或清零。旧后台未声明删除协议时，按钮禁用；重新打开软件加载更新后再操作。
7. 打开交付，如何判断是有效结果
在“选中流水线”使用打开成品 / 试玩、打开交付、查看预览。查看真实 QA 的范围、当前目标与 revision、实际源码和资源，而不是只看 AI 说“完成了”。
Blender 制作应有真实源文件、清单和对应 PNG；存入内存不等于保存后仍在磁盘。
游戏 / 软件应有真实可运行项目和机器检查；只输出说明或几张图片不等于软件通过。
在3.0，已验收终端与其他主动工位的完成情况分别记录；有必需未完成分支时全线仍等待。未触发的按需节点可以继续休眠。
可选分支被明确排除时，应显示真实警告和失败状态，不把它伪造为 DONE。
