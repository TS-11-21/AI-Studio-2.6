把接入、分工、交接和验收放在一个工作区。

  • 多成员分工：在固定角色团队中分别制作和研究，再汇总交接。
  • 进度可见：查看真实执行事件与成员日志，等待资料或人工回交时按需唤醒，避免持续等待调用。
  • 控制制作过程：暂停保存、调整可编辑的任务与预算，使用隔离工作目录、交接合同和真实验收。

使用边界：自动协议工位与桌面人工交接并存；你需自带受支持助手、工具和会员/API额度。结果质量及服务商实际费用仍需核对。

退出后台默认暂停；只关闭界面时，后台继续运行。

16项工作流便利性与适用边界
  1. 独立推进：1.0/2.6本机同时1条；3.0按版本或套餐上限并行多线，独立预算和状态，无需等待无依赖的另一条线。
  2. 自定分工：3.0可自建、命名、增删工位；1.0/2.6保留固定逻辑角色，并可配置受支持接入。
  3. 多助手协作：2.6/3.0可为工位配置多成员，分别制作、检查或研究；1.0使用单成员逻辑工位。
  4. 交接可编排：3.0可设置上下游或按需调用连线及逐边合同；必需交接依赖须无环，调用链有深度与循环保护。
  5. 按需补资料：缺资料时提出真实请求，受支持的研究交付回到调用方；3.0还可按call边请求其他工位成果。
  6. 减少等待调用：3.0区分基础制作与调用任务，推进符合依赖的就绪工作；等待交付时不持续调用模型，具体Token节省需实测。
  7. 你决定节奏：暂停整条线并保存，等收尾后再调整或恢复；恢复和收费审批仍由你明确决定。
  8. 有界检查返修：按任务合同检查成果，支持策略开启的至多两轮QA修复及明确重试；不把任意审核连线当作无限自动讨论循环。
  9. 配置持续保留：保存流水线配置与已落盘状态，不必每次重新设置。主动取消本次任务清产物，但保留流水线配置。
  10. 取消前确认：默认否，明确不可恢复的内容范围；可先暂停修改。取消后需保存新任务，再明确开始。
  11. 真实状态可见：查看工作、等待、执行事件和日志；故障只阻塞相关依赖，独立分支可按资源与账号限额继续。
  12. 独立API总预算：每线独立累计账本；总预算大于API成员额度之和是建议，不是硬性要求，也不重复计算工位共享上限。
  13. 增额由你批准：计量API成员不足可申请从总可用额度增加，AI不能自行增额；实际费用按供应商用量，阈值不是绝对账单硬封顶。
  14. 会员额度另算：第三方会员用量不计美元API预算，仍受会员Token、速率和账号限额；软件不代售模型额度。
  15. 尽量复用已有助手：复用受支持登录与设置，通过隔离配置、工作目录和MCP核验接入；自动协议与桌面人工交接分开，兼容性取决于adapter。
  16. 授权与AI费用分开：规划买断和月会员方案；自带助手、工具及会员/API额度，软件费不含第三方费用。销售、付款和跨设备授权仍为预览。

AI Studio 2.6

一个拥有独立流水线、多成员团队与分层预算的本地 AI 创作工作室。

Codex 桌面版是默认 GPT 工位；Claude Code 使用已配置的接入。研究智能体按需选择。模型的完成声明后面仍需要实际文件、工具证据与机器验收。

打开此控制面板只读取本地状态。模型、连接测试与付费任务不会自动启动。暂停后可调整本线目标、分工与预算，恢复仍需明确批准。
